# Configurar MCP do Mercado Pago no Cursor

## ✅ MCP Já Configurado

O servidor MCP do Mercado Pago foi adicionado ao seu `mcp.json`.

## 🔌 Conectar e Autenticar

### Passo 1: Abrir Configurações do Cursor

1. Pressione `Ctrl + ,` (ou `Cmd + ,` no Mac)
2. OU vá em **File → Settings**

### Passo 2: Acessar Tools & MCPs

1. No menu lateral, procure por **"Tools & MCPs"** ou **"Features"**
2. Você verá uma lista de servidores MCP
3. Procure por **"mercadopago-mcp-server"**

### Passo 3: Conectar

1. Clique no botão **"Connect"** ao lado do Mercado Pago
2. Se não aparecer, clique em **"Needs authentication"** (abaixo do nome)
3. Você será redirecionado para o site do Mercado Pago

### Passo 4: Autenticar no Site

1. Selecione seu **país** (Brasil)
2. Faça login na sua conta Mercado Pago
3. Autorize as permissões solicitadas
4. Você será automaticamente redirecionado de volta ao Cursor

### Passo 5: Confirmar Conexão

Após autenticar, o MCP estará pronto. Você verá um ícone verde ou status "Connected".

---

## 🛠️ O Que o MCP Permite Fazer

Com o MCP conectado, você pode diretamente no Cursor (via comandos ao assistente):

- ✅ Criar aplicações no Mercado Pago
- ✅ Obter credenciais (Access Token, Public Key)
- ✅ Configurar webhooks
- ✅ Criar usuários de teste
- ✅ Gerenciar saldos de teste
- ✅ Pesquisar documentação oficial
- ✅ Fazer medições de qualidade da integração
